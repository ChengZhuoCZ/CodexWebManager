## Qualified controls

- an access key read only from a private file;
- exact public-origin, Host, Origin, same-origin fetch, CSRF, and WebSocket subprotocol checks;
- one bounded browser session with revocation and authenticated WebSocket binding;
- a renderer allowlist, correlation ownership, state replay only after view readiness, and
  reconnect re-announcement without reloading the page;
- bounded streaming uploads into a private shared directory with cleanup;
- fail-closed filtering of credential-bearing requests and secret-shaped renderer output;
- loopback-only systemd listeners, with Tailnet access delegated to an explicit Tailscale handler.

reached `Sign in to ChatGPT`, reconnected one WebSocket without a page reload, announced view
readiness on both connections, and produced zero server rejections. The sign-in action was not
clicked.

present on the target returned the expected authenticated-bridge health/CSP profile and passed the
